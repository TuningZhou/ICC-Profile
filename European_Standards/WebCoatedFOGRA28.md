# Web Coated FOGRA28 / 轮转涂布纸 FOGRA28

## 概述 / Overview

**中文：** Web Coated FOGRA28 适用于轮转涂布纸（LWC）上的热固型胶印，基于 FOGRA28 特性数据。

**English:** Web Coated FOGRA28 targets heatset web offset on LWC paper, based on FOGRA28 characterization data.

---
