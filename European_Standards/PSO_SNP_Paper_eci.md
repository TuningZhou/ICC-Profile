# PSO SNP Paper (ECI) / PSO 标准新闻纸（ECI）

## 概述 / Overview

**中文：** PSO SNP Paper 适用于标准新闻纸上的冷固型轮转胶印（报纸印刷），基于 FOGRA47 特性数据，TAC 仅 240%。

**English:** PSO SNP Paper targets coldset web offset on standard newsprint, based on FOGRA47 characterization data with TAC of only 240%.

---

| 参数 / Parameter | 值 / Value |
|---|---|
| **文件名 / File Name** | `PSO_SNP_Paper_eci.icc` |
| **配置文件描述 / Profile Description** | PSO SNP Paper (ECI) |
| **标准参考 / Standard Reference** | FOGRA47 / ISO 12647-3 |
| **ICC 版本 / ICC Version** | 2.4.0 |
| **色彩空间 / Color Space** | CMYK |
| **设备类型 / Device Class** | 打印机 (Printer) |
| **PCS 连接空间 / Profile Connection Space** | Lab |
| **目标纸张 / Target Paper** | 标准新闻纸（SNP） / Standard newsprint paper (SNP) |
| **总墨量 / Total Area Coverage (TAC)** | 240% |
| **测量条件 / Measurement Condition** | M0 / M0 |

---

## 适用场景 / Typical Applications

**中文：**
- 报纸印刷
- 新闻纸冷固胶印

**English:**
- Newspaper printing
- Coldset web offset on newsprint

---

## 注意事项 / Notes

**中文：** 新闻纸吸墨性强，必须使用低 TAC。

**English:** Newsprint is highly absorbent; low TAC is mandatory.
