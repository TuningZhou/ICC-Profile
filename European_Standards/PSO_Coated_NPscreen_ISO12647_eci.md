# PSO Coated NPscreen (ECI) / PSO 涂布纸调频加网（ECI）

## 概述 / Overview

**中文：** PSO Coated NPscreen 专为涂布纸上的调频加网工艺设计，TAC 为 330%，基于 FOGRA39 特性数据。

**English:** PSO Coated NPscreen is designed for FM screening on coated paper with 330% TAC, based on FOGRA39 characterization data.
