# PSO Uncoated v3 (ECI) / PSO 非涂布纸 v3（ECI）

## 概述 / Overview

**中文：** PSO Uncoated v3 是最新一代欧洲非涂布纸标准配置文件，基于 FOGRA52 特性数据，采用 M1 测量条件。

**English:** PSO Uncoated v3 is the latest-generation European uncoated paper standard profile, based on FOGRA52 with M1 measurement condition.

---

## 技术参数 / Technical Specifications

| 参数 / Parameter | 值 / Value |
|---|---|
| **文件名 / File Name** | `PSOuncoated_v3_FOGRA52.icc` |
| **配置文件描述 / Profile Description** | PSO Uncoated v3 (FOGRA52) |
| **标准参考 / Standard Reference** | FOGRA52 / ISO 12647-2:2013 |
| **ICC 版本 / ICC Version** | 2.4.0 |
| **色彩空间 / Color Space** | CMYK |
| **设备类型 / Device Class** | 打印机 (Printer) |
| **PCS 连接空间 / Profile Connection Space** | Lab |
| **目标纸张 / Target Paper** | 非涂布白纸 / Uncoated white paper |
| **总墨量 / Total Area Coverage (TAC)** | 280% |
| **测量条件 / Measurement Condition** | M1（D50，OBA 补偿） / M1 (D50, OBA-compensated) |
