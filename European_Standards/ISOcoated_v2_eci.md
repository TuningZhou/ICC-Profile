# ISO Coated v2 (ECI) / ISO 涂布纸 v2（ECI）

## 概述 / Overview

**中文：** ISO Coated v2 (ECI) 是欧洲色彩促进会 (ECI) 发布的参考 ICC 配置文件，基于 FOGRA39 特性数据集。它是欧洲最常用的 CMYK 标准配置文件，广泛应用于商业印刷、出版、广告等领域。

**English:** ISO Coated v2 (ECI) is the reference ICC profile published by ECI (European Color Initiative), based on FOGRA39 characterization data. It is the most commonly used CMYK standard profile in Europe for commercial printing, publishing, and advertising.

---

## 技术参数 / Technical Specifications

| 参数 / Parameter | 值 / Value |
|---|---|
| **文件名 / File Name** | `ISOcoated_v2_eci.icc` |
| **配置文件描述 / Profile Description** | ISO Coated v2 (ECI) |
| **标准参考 / Standard Reference** | FOGRA39 / ISO 12647-2 |
| **ICC 版本 / ICC Version** | 2.4.0 |
| **色彩空间 / Color Space** | CMYK |
| **设备类型 / Device Class** | 打印机 (Printer) |
| **PCS 连接空间 / Profile Connection Space** | Lab |
| **目标纸张 / Target Paper** | 高光/亚光涂布纸（约 150 g/m²） / Premium coated gloss/matte paper (~150 g/m²) |
| **总墨量 / Total Area Coverage (TAC)** | 330% |
| **测量条件 / Measurement Condition** | M0（D50 标准光源） / M0 (D50 illuminant) |

## 注意事项 / Notes

**中文：** 欧洲印刷行业的事实标准。如使用 OBA 纸张或需 M1 测量，请改用 PSOcoated_v3.icc (FOGRA51)。

**English:** De facto standard for European print. For OBA papers or M1 measurement, use PSOcoated_v3.icc (FOGRA51) instead.
