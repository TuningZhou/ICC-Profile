# Coated FOGRA27 / 涂布纸 FOGRA27

## 概述 / Overview

**中文：** Coated FOGRA27 是基于 ISO 12647-2:2004 标准的欧洲涂布纸胶印配置文件，对应 FOGRA27 特性数据。该配置文件曾是欧洲商业印刷的主要标准，但现已被更新的 FOGRA39 所取代。

**English:** Coated FOGRA27 is a European offset printing profile based on ISO 12647-2:2004, corresponding to FOGRA characterization data set 27. It was formerly the primary European commercial printing standard but has been superseded by FOGRA39.
