# Uncoated FOGRA29 / 非涂布纸 FOGRA29

## 概述 / Overview

**中文：** Uncoated FOGRA29 是基于旧版 FOGRA29 特性数据的非涂布纸配置文件，已被 PSO_Uncoated 系列取代。
