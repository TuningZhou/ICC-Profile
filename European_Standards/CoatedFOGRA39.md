# Coated FOGRA39 / 涂布纸 FOGRA39

## 概述 / Overview

**中文：** Coated FOGRA39 是欧洲印刷行业使用最广泛的 CMYK 配置文件之一，基于 FOGRA39 特性数据集，适用于涂布纸胶版印刷。在 Adobe 等软件中常作为默认 CMYK 配置文件。

**English:** Coated FOGRA39 is one of the most widely used CMYK profiles in the European print industry, based on FOGRA characterization data set 39 for coated paper offset printing. It is the default CMYK profile in many Adobe applications.

---

## 技术参数 / Technical Specifications

| 参数 / Parameter | 值 / Value |
|---|---|
| **文件名 / File Name** | `CoatedFOGRA39.icc` |
| **配置文件描述 / Profile Description** | Coated FOGRA39 (ISO 12647-2:2004) |
| **标准参考 / Standard Reference** | ISO 12647-2:2004/Amd 1 / FOGRA39 |
| **ICC 版本 / ICC Version** | 2.1.0 |
| **色彩空间 / Color Space** | CMYK |
| **设备类型 / Device Class** | 打印机 (Printer) |
| **PCS 连接空间 / Profile Connection Space** | Lab |
| **目标纸张 / Target Paper** | 涂布纸（约 115 g/m²） / Coated paper (~115 g/m²) |
| **总墨量 / Total Area Coverage (TAC)** | 330% |
| **测量条件 / Measurement Condition** | M0（D50 标准光源） / M0 (D50 illuminant) |

## 注意事项 / Notes

**中文：** Adobe 软件默认 CMYK 空间。如需更低墨量，可选 ISOcoated_v2_300_eci.icc。

**English:** Default CMYK in Adobe software. For lower ink coverage, consider ISOcoated_v2_300_eci.icc.
