# eciCMYK v2 (ECI) / eciCMYK v2（ECI 交换空间）

## 概述 / Overview

**中文：** eciCMYK v2 是 ECI 发布的设备无关 CMYK 交换色彩空间。它不针对任何特定纸张或印刷条件，而是作为安全的 CMYK 中间格式，用于在不同印刷条件之间传递文件时保留色彩信息。

**English:** eciCMYK v2 is a device-independent CMYK exchange color space published by ECI. It does not target any specific paper or printing condition, but serves as a safe CMYK intermediary to preserve color information when transferring files between different print conditions.
