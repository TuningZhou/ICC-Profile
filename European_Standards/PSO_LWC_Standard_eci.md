# PSO LWC Standard (ECI) / PSO 标准轻涂纸（ECI）

## 概述 / Overview

**中文：** PSO LWC Standard 适用于标准轻量涂布纸上的热固型轮转胶印，基于 FOGRA44 特性数据。

**English:** PSO LWC Standard targets heatset web offset on standard LWC paper, based on FOGRA44 characterization data.

---
