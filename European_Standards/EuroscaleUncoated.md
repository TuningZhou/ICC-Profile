# Euroscale Uncoated v2 / 欧洲标准非涂布纸

## 概述 / Overview

**中文：** Euroscale Uncoated 是 ISO 12647 系列标准建立之前欧洲使用的传统非涂布纸印刷配置文件。

**English:** Euroscale Uncoated is a legacy European uncoated paper printing profile from before the ISO 12647 standard era.
