# Euroscale Coated v2 / 欧洲标准涂布纸

## 概述 / Overview

**中文：** Euroscale Coated 是 ISO 12647 系列标准建立之前欧洲使用的传统涂布纸印刷配置文件。现已被 FOGRA 系列配置文件取代。

**English:** Euroscale Coated is a legacy European coated paper printing profile from before the ISO 12647 standard era. It has been superseded by FOGRA-based profiles.
