# ISO Coated v2 300% (ECI) / ISO 涂布纸 v2 300%（ECI）

## 概述 / Overview

**中文：** ISO Coated v2 300% 是 ISO Coated v2 的低墨量变体，将总墨量从 330% 降至 300%，适用于对墨量敏感的涂布纸基材，如薄纸或特种涂布纸。由 ECI（欧洲色彩促进会）发布。

**English:** ISO Coated v2 300% is the reduced ink variant of ISO Coated v2, lowering TAC from 330% to 300%. Suitable for coated substrates sensitive to heavy ink coverage. Published by ECI.
