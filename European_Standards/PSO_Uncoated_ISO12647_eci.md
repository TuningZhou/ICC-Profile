# PSO Uncoated (ECI) / PSO 非涂布纸（ECI）

## 概述 / Overview

**中文：** PSO Uncoated 适用于白色非涂布胶版纸的胶印，基于 FOGRA47 特性数据。是欧洲非涂布纸印刷的标准配置文件。

**English:** PSO Uncoated targets offset printing on white uncoated offset paper, based on FOGRA47 characterization data. It is the standard profile for uncoated paper printing in Europe.

---

## 技术参数 / Technical Specifications

| 参数 / Parameter | 值 / Value |
|---|---|
| **文件名 / File Name** | `PSO_Uncoated_ISO12647_eci.icc` |
| **配置文件描述 / Profile Description** | PSO Uncoated ISO12647 (ECI) |
| **标准参考 / Standard Reference** | FOGRA47 / ISO 12647-2 |
| **ICC 版本 / ICC Version** | 2.4.0 |
| **色彩空间 / Color Space** | CMYK |
| **设备类型 / Device Class** | 打印机 (Printer) |
| **PCS 连接空间 / Profile Connection Space** | Lab |
| **目标纸张 / Target Paper** | 非涂布白色胶版纸 / Uncoated white offset paper |
| **总墨量 / Total Area Coverage (TAC)** | 280% |
| **测量条件 / Measurement Condition** | M0 / M0 |

---

## 适用场景 / Typical Applications

**中文：**
- 书籍与文档印刷
- 信纸与文具
- 非涂布纸胶印

**English:**
- Book & document printing
- Letterheads & stationery
- Offset on uncoated paper

---

## 注意事项 / Notes

**中文：** 白色非涂布纸专用；微黄纸张使用 ISOuncoatedyellowish.icc。

**English:** For white uncoated paper; use ISOuncoatedyellowish.icc for yellowish stock.
