# PSO Coated v3 (ECI) / PSO 涂布纸 v3（ECI）

## 概述 / Overview

**中文：** PSO Coated v3 是最新一代欧洲涂布纸标准配置文件，基于 FOGRA51 特性数据。与旧版 FOGRA39 的关键区别在于采用 M1 测量条件，可正确处理含荧光增白剂（OBA）的纸张。

**English:** PSO Coated v3 is the latest-generation European coated paper standard profile, based on FOGRA51 characterization data. The key difference from older FOGRA39 is the M1 measurement condition, which correctly handles papers containing optical brightening agents (OBA).
