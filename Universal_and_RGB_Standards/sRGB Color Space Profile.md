# sRGB IEC61966-2.1 / sRGB IEC61966-2.1

## 概述 / Overview

**中文：** sRGB 是由 HP 和 Microsoft 于 1996 年联合开发的标准 RGB 色彩空间，现已成为互联网、消费级显示器和数码相机的默认色彩空间。几乎所有网页浏览器和操作系统都默认使用 sRGB。

**English:** sRGB is the standard RGB color space jointly developed by HP and Microsoft in 1996. It has become the default color space for the internet, consumer displays, and digital cameras. Nearly all web browsers and operating systems use sRGB by default.
