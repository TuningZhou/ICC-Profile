# ColorMatch RGB / ColorMatch RGB

## 概述 / Overview

**中文：** ColorMatch RGB 是由 Radius 公司为其 PressView 显示器定义的 RGB 色彩空间，用于在屏幕上模拟印刷效果。如今已过时。

**English:** ColorMatch RGB was defined by Radius for its PressView monitors to simulate print output on screen. Now obsolete.
