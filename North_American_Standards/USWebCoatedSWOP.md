# U.S. Web Coated (SWOP) v2 / 美国轮转涂布纸（SWOP）v2

## 概述 / Overview

**中文：** U.S. Web Coated (SWOP) v2 是北美最广泛使用的 CMYK 配置文件，基于 SWOP（Specifications for Web Offset Publications）标准。在 Adobe 软件中常作为北美默认 CMYK 配置文件。

**English:** U.S. Web Coated (SWOP) v2 is the most widely used CMYK profile in North America, based on SWOP (Specifications for Web Offset Publications). It is the default North American CMYK profile in Adobe software.

---

**English:** De facto standard for North American printing, equivalent to Europe's FOGRA39.
