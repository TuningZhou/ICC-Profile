# Web Coated SWOP 2006 Grade 3 / 轮转涂布纸 SWOP 2006 Grade 3

## 概述 / Overview

**中文：** Web Coated SWOP 2006 Grade 3 针对 SWOP 2006 标准的 Grade 3 轮转涂布纸，是对旧版 SWOP 的更新。

**English:** Web Coated SWOP 2006 Grade 3 targets SWOP 2006 standard grade 3 web coated paper, an update to the older SWOP standard.
