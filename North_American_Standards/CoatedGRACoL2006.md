# GRACoL 2006 Coated #1 / GRACoL 2006 涂布纸 #1

## 概述 / Overview

**中文：** GRACoL 2006 是北美 IDEAlliance 组织发布的涂布纸 #1 配置文件，基于 CRPC1 参考打印条件。广泛用于北美商业单张纸胶印。

**English:** GRACoL 2006 is the premium coated #1 profile published by IDEAlliance, based on CRPC1 reference print condition. Widely used for North American commercial sheetfed offset.

---
