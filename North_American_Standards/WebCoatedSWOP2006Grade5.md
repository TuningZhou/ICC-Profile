# Web Coated SWOP 2006 Grade 5 / 轮转涂布纸 SWOP 2006 Grade 5

## 概述 / Overview

**中文：** Web Coated SWOP 2006 Grade 5 针对 SWOP 2006 标准的 Grade 5 轮转涂布纸。Grade 5 纸张品质高于 Grade 3。

**English:** Web Coated SWOP 2006 Grade 5 targets SWOP 2006 standard grade 5 web coated paper. Grade 5 offers higher quality than grade 3.
