# US Newsprint (SNAP 2007) / 美国新闻纸（SNAP 2007）

## 概述 / Overview

**中文：** US Newsprint SNAP 2007 是北美报纸印刷的标准配置文件，基于 SNAP（Specifications for Newsprint Advertising Production）2007 规范。

**English:** US Newsprint SNAP 2007 is the standard profile for North American newspaper printing, based on SNAP (Specifications for Newsprint Advertising Production) 2007.

---

## 技术参数 / Technical Specifications

| 参数 / Parameter | 值 / Value |
|---|---|
| **文件名 / File Name** | `USNewsprintSNAP2007.icc` |
| **配置文件描述 / Profile Description** | US Newsprint (SNAP 2007) |
| **标准参考 / Standard Reference** | SNAP 2007 |
| **ICC 版本 / ICC Version** | 2.1.0 |
| **色彩空间 / Color Space** | CMYK |
| **设备类型 / Device Class** | 打印机 (Printer) |
| **PCS 连接空间 / Profile Connection Space** | Lab |
| **目标纸张 / Target Paper** | 标准新闻纸 / Standard newsprint |
| **总墨量 / Total Area Coverage (TAC)** | 240% |
| **测量条件 / Measurement Condition** | M0 / M0 |
