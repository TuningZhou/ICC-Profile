# Japan Color 2011 Coated / Japan Color 2011 涂布纸

## 概述 / Overview

**中文：** Japan Color 2011 Coated 是日本印刷标准的最新版本，对 2001 版进行了更新和改进，提供更准确的涂布纸色彩表现。

**English:** Japan Color 2011 Coated is the latest Japanese printing standard, an update to the 2001 version with improved coated paper color accuracy.
