# Japan Color 2002 Newspaper / Japan Color 2002 新闻纸

## 概述 / Overview

**中文：** Japan Color 2002 Newspaper 是日本报纸印刷的标准配置文件。

**English:** Japan Color 2002 Newspaper is the standard profile for Japanese newspaper printing.

---

| 参数 / Parameter | 值 / Value |
|---|---|
| **文件名 / File Name** | `JapanColor2002Newspaper.icc` |
| **配置文件描述 / Profile Description** | Japan Color 2002 Newspaper |
| **标准参考 / Standard Reference** | Japan Color 2002 |
| **ICC 版本 / ICC Version** | 2.1.0 |
| **色彩空间 / Color Space** | CMYK |
| **设备类型 / Device Class** | 打印机 (Printer) |
| **PCS 连接空间 / Profile Connection Space** | Lab |
| **目标纸张 / Target Paper** | 标准新闻纸 / Standard newsprint |
| **总墨量 / Total Area Coverage (TAC)** | 240% |
| **测量条件 / Measurement Condition** | M0 / M0 |
