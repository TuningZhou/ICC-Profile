# Japan Color 2001 Coated / Japan Color 2001 涂布纸

## 概述 / Overview

**中文：** Japan Color 2001 Coated 是日本印刷技术协会 (JPMA) 制定的涂布纸标准配置文件，广泛用于日本商业印刷。

**English:** Japan Color 2001 Coated is a coated paper standard profile from JPMA, widely used in Japanese commercial printing.

---

## 技术参数 / Technical Specifications

| 参数 / Parameter | 值 / Value |
|---|---|
| **文件名 / File Name** | `JapanColor2001Coated.icc` |
| **配置文件描述 / Profile Description** | Japan Color 2001 Coated |
| **标准参考 / Standard Reference** | Japan Color 2001 |
| **ICC 版本 / ICC Version** | 2.1.0 |
| **色彩空间 / Color Space** | CMYK |
| **设备类型 / Device Class** | 打印机 (Printer) |

| **目标纸张 / Target Paper** | 涂布美术纸 / Coated art paper |
| **总墨量 / Total Area Coverage (TAC)** | 350% |
| **测量条件 / Measurement Condition** | M0 / M0 |
