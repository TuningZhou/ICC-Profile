# Japan Web Coated (Ad) / Japan Web Coated（广告）

## 概述 / Overview

**中文：** Japan Web Coated (Ad) 专为日本杂志广告轮转胶印设计，TAC 为 300%。

**English:** Japan Web Coated (Ad) is designed for Japanese magazine advertising web offset with 300% TAC.
